# Phase 0B Format Pilot

These five tasks are throwaway formatting probes, not held-out benchmark tasks and not corpus material.

Purpose:
- observe raw native-FIM output from the real Qwen2.5-Coder-0.5B base Q4_K_M model,
- verify indentation behavior,
- observe stop/special-token behavior,
- observe suffix repetition,
- turn observed raw shapes into fixed normalizer regression fixtures.

The pilot must run before Claude authors the held-out benchmark set.
